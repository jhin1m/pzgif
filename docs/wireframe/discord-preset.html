Discord GIF size limits, in one place

Discord's upload limits are strict and the error messages are not helpful. An animated emoji has to be 256 KB or less, and the recommended canvas is 128×128 — anything larger is scaled down on display anyway, so the extra pixels cost you budget for nothing. Stickers are a different pipeline with a different ceiling, and server icons and profile banners are far more forgiving. Pick the preset that matches what you are uploading and the target is applied for you.

The usual reason a GIF blows past 256 KB is frame count, not resolution. A ten-frame loop at 128×128 is tiny; a sixty-frame loop at the same size is six times the data. If auto-fit has to push quality lower than you would like, the fastest fix is to trim the loop or drop every second frame — at emoji size nobody will notice, and you get the quality budget back.

Why does my emoji look blurry after upload?

Because it was scaled twice. If you upload a 480×480 GIF, Discord scales it down for display using its own resampler, on top of whatever compression you already applied. Exporting at exactly 128×128 gives a sharper result at the same file size — which is what the Emoji preset does before it touches quality at all.
